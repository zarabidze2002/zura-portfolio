# 🌐 Zura.dev — Personal Portfolio

A modern, minimalistic portfolio built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**, structured as a monorepo with **Turborepo**.  
It showcases my work, skills, and open-source projects — designed for speed, clarity, and a delightful developer experience.

## 🚀 Tech Stack
- ⚡ **Next.js 15 (App Router)**
- 💎 **TypeScript + Tailwind CSS**
- 🧱 **Turborepo Monorepo**
- 🌗 **Dark / Light Theme Toggle (localStorage)**
- 🎨 **Responsive, minimal UI**

## 🛠️ Setup

```bash
git clone https://github.com/zarabidze2002/zura-portfolio.git
cd zura-portfolio
pnpm install
pnpm dev

```
